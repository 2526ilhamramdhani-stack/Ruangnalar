BAB 02 · 8 MENIT BACA

Fungsi Komposisi

Komposisi fungsi adalah penggabungan dua fungsi secara berurutan. Notasi (g ∘ f)(x) dibaca “g komposisi f” dan berarti hasil dari f dimasukkan ke fungsi g.

(g ∘ f)(x) = g(f(x))

1. Komposisi melalui pasangan terurut

Kerjakan fungsi paling kanan terlebih dahulu. Jika h(0) = −4 dan g(−4) = −6, maka (g ∘ h)(0) = −6. Ulangi langkah ini untuk setiap input yang tersedia.

Ingat: output fungsi pertama menjadi input untuk fungsi berikutnya. Jangan menukar urutan komposisi.

2. Komposisi aljabar

Jika f(x) = 3x − 1 dan g(x) = 2x² − 3, masukkan seluruh ekspresi f(x) ke setiap x pada g(x).

g(f(x)) = 2(3x − 1)² − 3
= 18x² − 12x − 1

3. Fungsi invers

Fungsi g merupakan invers f jika kedua komposisi menghasilkan identitas pada domain yang sesuai: f(g(x)) = x dan g(f(x)) = x.

INVERS FUNGSI · STRATEGI

Mengapa pangkat tiga dan akar pangkat tiga saling membatalkan?

Perhatikan dua fungsi berikut: f(x) = x³ + 5 dan g(x) = ∛(x − 5). Strategi terbaik adalah membaca operasi yang dilakukan fungsi pertama, lalu membalik urutannya.

Langkah 1 — Susun operasi kebalikan

Fungsi f mengalikan input dengan dirinya tiga kali, lalu menambahkan 5. Fungsi g mengurangi 5 lebih dahulu, kemudian mengambil akar pangkat tiga. Urutan operasi kebalikan harus dibalik.

f(g(x)) = (∛(x − 5))³ + 5 = x

Langkah 2 — Verifikasi dari arah sebaliknya

g(f(x)) = ∛((x³ + 5) − 5) = x

Kedua komposisi kembali ke input awal. Karena akar pangkat tiga berlaku untuk bilangan real negatif maupun positif, identitas ∛(x³) = x berlaku untuk semua x real.

Jebakan umum: jangan menyederhanakan ∛(x − 5) menjadi ∛x − 5. Angka −5 berada di dalam tanda akar. Selain itu, periksa kedua arah komposisi, bukan hanya satu.

Intuisi geometri: simetri terhadap y = x

Jika f(a) = b, maka fungsi invers mengembalikan b menjadi a. Titik (a,b) pada grafik f berpasangan dengan titik (b,a) pada grafik f⁻¹. Pertukaran koordinat ini merupakan pencerminan terhadap garis y = x.
